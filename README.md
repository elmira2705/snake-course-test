# Snake Game in Python

A simple, classic Snake game built using the `pygame` library.

## Prerequisites

Before running the game, you need to have Python installed on your system. You also need to install the `pygame` library.

### 1. Install pygame

Open your terminal or command prompt and run:

```bash
pip install pygame
```

## How to Play

### 1. Run the Game

Execute the following command in your terminal:

```bash
python snake.py
```

### 2. Controls

- **Arrow Keys**: Move the snake (Up, Down, Left, Right).
- **Q**: Quit the game (after losing).
- **C**: Play again (after losing).

### 3. Objective

Eat the green food blocks to grow longer and increase your score. Avoid hitting the boundaries of the window or the snake's own body!

## Features

- Real-time score tracking.
- Increasing difficulty (snake gets longer).
- "Game Over" screen with options to restart or quit.
