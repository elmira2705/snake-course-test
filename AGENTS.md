# AGENTS.md

## Repo overview

Single-file Snake game (`snake.py`) using `pygame`. Procedural game loop with event-driven input. No package manager, no tests, no CI, no lint/typecheck config.

## Commands

```bash
pip install pygame   # install dependency
python snake.py      # run the game
```

No other commands exist.

## Controls (hardcoded in snake.py)

- Arrow keys: move
- C: play again after game over
- Q: quit after game over

## Notable

- Game over screen uses recursive `gameLoop()` call (press C). This means each restart adds a stack frame — acceptable for casual play but not production-clean.
- `GEMINI.md` is a legacy context file from when this was generated by Gemini CLI. Keep it in sync or remove it.
- No automated tests — manual playtesting only.
